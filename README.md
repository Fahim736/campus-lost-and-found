# Campus Lost & Found

A comprehensive web-based portal designed for university students, faculty, and staff to easily report, track, and recover lost and found items on campus.

## Key Features

- **User Authentication:** Secure user registration, login, and logout functionality.
- **Report Lost Items:** Users can post details, descriptions, locations, and images of lost belongings.
- **Report Found Items:** Option to post details about items found around the campus to help owners locate them.
- **Search & Filter:** Easily search and filter reported items by category, location, or date.
- **Claim & Status Tracking:** Track item recovery status (Open, Pending, Claimed/Resolved).
- **Ownership Authorization:** Only item owners or original reporters can manage, edit, or delete their submitted reports.

## Tech Stack

- **Backend:** Python & Django Framework
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Database:** SQLite (Default local database)
- **Version Control:** Git & GitHub
